\ssr{ЗАКЛЮЧЕНИЕ}

В рамках лабораторной работы была построена гибридная рекомендательная система на основе алгоритма матричной факторизации методом SVD и контентной фильтрации с поиском похожих игр по косинусной мере.

По результатам измерений оптимальное значение количества латентных факторов составило 25, а оптимальная доля оценок, полученных с помощью матричной факторизации, составила 0.3.  Именно при таких значениях настроечных параметров было достигнуто минимальное значение ошибки RMSE --- 1.2150.

Гибридная рекомендательная система оказалась точнее каждого использованного алгоритма в отдельности
